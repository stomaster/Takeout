# E-commerce Platform Backend

## Project Introduction
Spring Boot + MyBatis e-commerce platform backend project.

## Tech Stack
- Spring Boot 3.5.11
- MyBatis 3.0.5
- MySQL 8.0
- Maven
- Java 17

## Quick Start
1. Clone project
2. Import to IDEA
3. Create database ecommerce_demo
4. Run EcommerceDemoApplication.java
5. Test API: http://localhost:8081/api/users
